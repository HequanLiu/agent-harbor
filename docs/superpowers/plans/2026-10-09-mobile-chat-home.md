# 移动首页直接聊天

用户要求：首页默认显示对话框，自动选择一个 Agent 和模型。

实现：index 作为默认会话入口；第一个 Agent，优先恢复其最近仍有有效模型凭据的会话，没有则选已有服务的首个未 sunset 模型并创建会话。无配置显示明确引导。旧首页移动到 history，聊天页展示默认 Agent/模型，保留会话列表入口。默认选择不触发模型调用。

步骤：先添加默认选择测试；实现 core/default-chat 与 index 自动进入；调整 history 和聊天导航；用隔离后端验证登录直接出现输入框、模型、发送/重连/停止和历史入口。类型检查、lint、单测、Web 构建通过后交付。
